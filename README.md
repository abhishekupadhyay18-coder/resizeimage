# 🚀 Image Resizer

> **A fast, modern and privacy-focused web application for resizing and compressing images directly in the browser.**

🌐 **Live Website:**  
https://imageresizer-navy.vercel.app

---

# ✨ Features

- ✅ Resize images with custom dimensions
- ✅ Compress images while maintaining quality
- ✅ Custom output file size
- ✅ Fast browser-based processing
- ✅ Mobile & Desktop Friendly
- ✅ Clean and Modern User Interface
- ✅ No unnecessary uploads for processing (where applicable)
- ✅ Quick Download

---

# 🛠 Tech Stack

- **React**
- **TypeScript**
- **Vite**
- **Tailwind CSS**
